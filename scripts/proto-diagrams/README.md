# Flow diagram demo (design system v1.2, 2026-09-23)

`lectures/proto-diagrams.html` is the reference demo of the lu-flow
component (`assets/lu-flow.js`, styles in `assets/lu.css` section 8d).
Rebuild it with `python3 builddemo.py` (paths inside point at the scratch
folder it was written in). `spec.json` is the diagram used in the demo.

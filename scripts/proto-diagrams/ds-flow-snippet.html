Route 0 · Flow diagram, for anything with blocks and arrows (v1.2)

One JSON spec lists blocks, arrows and steps; assets/lu-flow.js draws it. Arrows name their two blocks, so they can never drift off them. Put it inside a .lu-walk and the step bar drives it: dots run along the current arrow, blocks change state. Colour is meaning, set by kind and state, never by a hex value. Load lu-flow.js after lu-deck.js. Full demo: lectures/proto-diagrams.html.
